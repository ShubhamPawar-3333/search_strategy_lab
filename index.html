Rules used in every run

  1. Children are generated in alphabetical order.
  2. Queue (breadth-first): children join at the back in that order; nodes leave from the front. Stack (depth-first): children are pushed in reverse alphabetical order, so the alphabetically first child ends up on top; nodes leave from the top.
  3. Priority queue (uniform-cost, greedy, A*): after the children are added, the whole frontier is sorted by its value (g, h or f); equal values go in alphabetical order. The lowest value leaves first.
  4. The goal test is done when a node is taken out of the frontier, not when it is added.
  5. For every child, ask two questions. Already visited? Ignore it. Already in the frontier? Breadth-first and depth-first ignore it; uniform-cost, greedy and A* keep the lower value, changing the parent if the new path is better.
  6. A node is visited once it has come into the frontier and gone out again, that is, once it has been taken out and expanded.
  7. Breadth-first and depth-first do not use road costs, so costs are hidden for them.
